부록 A-2. 분석자료 및 재현 절차

2026년 7월 조사에서 보존한 robots.txt 응답과 표본 자료를 이용하여 판정과 주요 통계를 다시 계산하는 자료입니다. 전체 자료를 내려받아 아래 순서로 실행하면, 보존된 판정표와 재계산 결과가 일치하는지 확인할 수 있습니다.

재현 범위와 자료의 구분

robots.txt 분석은 보존 자료로 재계산합니다. 수집 결과 1,199행의 복원, 16개 토큰의 재판정, 주요 집계와 회귀분석을 포함합니다. 당시 통계 검정·회귀 스크립트는 제공된 원자료 ZIP에서 확인되지 않아, 해당 분석 코드는 보존 자료와 논문 분석 명세에 따라 이번에 재구성했습니다.

이용약관 분석(RQ3)의 전체 재현은 포함하지 않습니다. 181개 사이트의 최종 행별 수작업 코딩표가 제공 자료에 없으므로, 금지·제한 14건 및 부재·확인 불가 31건 등의 집계는 독립 재현의 검증 범위에서 제외했습니다.

전체 재현 자료 다운로드 (ZIP) 분석 코드 보기 · GitHub

GitHub의 source 폴더는 코드를 열람하기 위한 사본입니다. 전체 실행에는 입력 자료와 검증 파일이 포함된 위 ZIP을 사용하세요.

1. 확인된 재현 결과

2026년 9월 30일 Windows·Python 3.12.14 환경에서 실행했습니다. 표본 프레임·최초 수집·재시도 자료로 복원한 1,199행×46열이 최종 입력 CSV와 모든 셀에서 일치했습니다. 저장 원문을 재판정한 long 파일 17,216행×16열과 wide 파일 1,076행×55열도 보존된 판정표와 모든 셀에서 일치했습니다.

17,216행은 판독 불가 도메인까지 포함한 재판정 파일의 행 수입니다. 본 분석의 15,280건은 판독 가능한 955개 도메인×16개 토큰을 뜻합니다.

통계 재계산에는 층별 카이제곱 검정, 층 로지스틱 회귀, 웹 운영 성숙도 보조모형과 민감도 분석 등이 포함됩니다. 주 분석의 Pearson χ²는 76.33211197이며, 개인·창작 층의 주모형 오즈비는 0.39713775로 계산되었습니다.

2. 내려받기와 실행

  1. 전체 ZIP을 내려받아 압축을 풉니다.
  2. Python 3.12를 준비합니다.
  3. 압축을 푼 폴더 중 README.md와 requirements.txt가 있는 최상위 폴더에서 터미널을 엽니다.
  4. 아래 네 명령을 위에서부터 차례로 실행합니다.

Windows PowerShell

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m robots_study

가상환경을 별도로 활성화할 필요는 없습니다. 최초 패키지 설치에는 인터넷이 필요하지만, 설치 후 기본 분석은 저장 자료만 사용하며 웹사이트를 다시 수집하지 않습니다.

macOS / Linux 실행 명령

동일한 실행 절차를 위한 명령입니다. 이번 검증에서 macOS/Linux의 실제 실행까지 확인한 것은 아닙니다.

python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m robots_study

이미 results/reproduction 폴더가 있으면 새 출력 경로를 지정합니다. 프로그램은 기존 결과와 입력 파일을 덮어쓰지 않습니다.

.\.venv\Scripts\python.exe -m robots_study --output results/reproduction_2

고정된 의존성 버전은 이번 재현 검증에 사용한 환경입니다. 2026년 7월 조사 당시의 정확한 설치 버전을 확인한 것은 아닙니다.

3. 실행 결과 확인

기본 실행은 입력 파일 해시 확인 → 1,199행 입력 복원·비교 → 저장 원문 재판정·비교 → 주요 집계 검증 → 통계·공유 도메인·기능군 분석의 순서로 진행됩니다. 입력이 빠지거나 보존된 판정과 결과가 다르면 오류로 종료합니다.

  • results/reproduction/validation.json: 이번 실행의 환경, 파일 비교 및 집계 검증 결과
  • results/reproduction/: 재계산한 CSV·JSON 결과 파일
  • verification/validation_windows_py312.json: 배포 전에 수행한 Windows 검증 기록
  • docs/reproducibility.md: 재현 가능한 범위와 미확보 자료
  • docs/provenance.md: 자료 계보와 이번 코드 정리 내역
  • data/source_manifest.csv: 입력 자료의 원본 경로, 해시와 변환 여부

4. 해석과 추가 확인

계산의 재현은 표본의 대표성이나 모든 분류의 타당성을 보증하지 않습니다. 기능군은 최종 원고 부록 B의 배정을 계산용 설정으로 옮긴 것이며, 플랫폼 호스팅 분류도 개별 이용자의 실제 설정 권한을 새로 검증한 결과는 아닙니다.

RQ3를 완전히 재현하려면 181개 사이트별 최종 코드, 판단 당시 약관 URL·시점, 근거 조항, 검토 이력과 robots.txt 판정의 결합 규칙이 추가로 필요합니다. ZIP의 terms_coding_template.csv는 이를 복구하기 위한 작업용 양식이며, 빈 판단 칸을 최종 결과로 채운 자료가 아닙니다.

새 수집용 스크립트는 현재 웹을 조회하므로 과거 조사 결과의 재현과 구분해야 합니다. 이 페이지의 기본 실행 절차는 새 수집을 포함하지 않습니다. 원문 응답과 약관의 권리는 각 원출처에 있습니다.
