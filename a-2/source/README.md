# A-2 코드 열람용 사본

이 폴더는 분석 코드와 방법 문서를 GitHub에서 읽기 위한 사본입니다.
모든 실행 입력과 검증 기록은 [전체 재현 패키지](../downloads/robots-study-repro_20260930.zip)에 들어 있습니다.
실행할 때는 이 코드 폴더만 받지 말고 전체 ZIP을 내려받아 압축을 푼 뒤, 그 안의 README를 따라 주세요.

- `robots_study/`: 저장 원문 재판정과 통계 분석
- `collection/`: 새 시점의 수집 도구
- `tests/`: 판정 경계 사례 점검
- `docs/`: 방법과 자료 계보, 재현 범위
- `requirements.txt`: 검증 환경의 패키지 버전

코드 사본은 2026-09-30 배포 ZIP에 포함된 해당 파일과 동일합니다.
약관의 최종 행별 수작업 코딩 기록은 제공 자료에 없어, 약관 결과의 완전 재현은 포함하지 않습니다.
