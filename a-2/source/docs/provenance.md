# 자료 계보와 코드 정리 내역

## 보존 자료

원자료는 사용자가 제공한 `robot.txt work.zip`이다. 이 작업은 원본 ZIP과 원고를 수정하지 않았다. `data/source_manifest.csv`에 배포한 각 입력의 원래 경로와 SHA-256을 기록한다. 동일 파일이면 원본·배포 해시가 같다. 최종 원고에서 옮긴 기능 분류 설정은 ZIP의 역사 자료와 구분해 표시한다.

본수집 프레임은 1,200행이다. `수집대상=N` 1행을 제외하면 1,199행이며, 도메인의 최초 등장 행을 남기면 1,076개다. 최초 본수집의 판독 가능 도메인은 953개(200 응답 880개, 파일 부재 73개)다. 실패 대상 재시도에서 2개 도메인이 회복되어 최종 955개가 됐다. 재시도 결과를 반영하고 프레임의 원래 행 순서로 펼친 파일이 `snapshot_allrows.csv`다.

재판정 당시에는 이 파일과 보존 원문을 사용했다. 저장 원문은 896개이며 최종 표본에 연결되는 882개와 이전 표본에서 남은 14개를 포함한다. 기본 분석은 원문 폴더 전체를 표본으로 간주하지 않는다.

## 배포본에서 변환한 입력

- `master_frame.xlsx`와 `terms_crosstab.xlsx`의 작성자 컴퓨터 절대경로 메타데이터만 제거했다. 셀 값·수식은 바꾸지 않았다.
- `blackyakmall.com.txt`는 robots.txt 요청에 돌아온 HTML 응답이다. 여기에 포함된 웹 SDK 설정값 2개를 배포본에서 마스킹했다. robots 지시문은 그대로이며, 원본과 배포본의 16개 토큰 판정이 모두 일치함을 확인했다. 원본·배포 해시는 manifest에 각각 기록했다.
- 그 밖의 robots·약관 텍스트는 설명용 주석을 포함해 관측 자료로 보존했다. HTTP 원시 바이트가 아니라 당시 수집기가 저장한 디코딩 텍스트다.
- `.claude` 설정, 대화용 메모, 캐시, 실행 로그, 중복 압축파일과 원고 초안은 분석 입력이 아니므로 저장소 배포에서 제외했다.

## 코드

`recode.py`의 그룹 분리·명시·규칙 적용·하위 경로 판정은 원래 `recode_5category.py`의 의미를 유지했다. 함수명이 드러내는 간단한 책임으로 나누고, 개인 경로와 날짜별 출력 경로를 인자로 바꿨다. 저장 원문 전체 896개×16토큰에서 원래 함수와 새 함수의 판정이 동일함을 별도로 확인했다.

`statistics.py`, `platforms.py`, `function_groups.py`, 입력 계보·검증 코드는 이번 배포를 위해 구성했다. 원본에 없던 통계 검정 코드를 예전부터 보존된 것처럼 표시하지 않는다. 기능군은 옛 코드의 분류를 몰래 덮어쓰지 않고 최종 원고 부록 B의 설정 파일로 분리했다.

수집기는 원래 동작을 보존하되 다음을 고쳤다.

- User-agent 값의 인라인 주석을 제거한 뒤 명시 여부를 비교한다.
- 기본 입력 경로를 저장소 내부로 바꿨다.
- 새 출력 폴더를 명시하게 하고 기존 폴더·입력 파일의 덮어쓰기를 막았다.
- 최신 파일을 자동 선택하던 `--resume`을 제거했다.
- 약관 자동 수집 결과는 원본 엑셀 대신 새 사본에 쓴다.

`retry_failed.py`와 `mark_manual_check.py`의 import 즉시 네트워크 요청·파일 수정 동작은 배포 진입점에 포함하지 않았다. 옛 `expand_allrows.py`의 최신 파일 자동 선택도 사용하지 않는다. 원래 7개 Python 파일의 경로와 해시는 `data/original_scripts.json`에 기록했다. 이 목록은 당시 모든 통계 코드가 있었다는 증거가 아니다.

코드의 설명 주석·docstring을 제거했으나 계산 규칙이나 결과를 바꿔 작성 주체를 꾸미지는 않았다. 이번 정리와 통계 재구성의 시점은 2026년 9월 30일이다.

## 환경

원본에는 `requests>=2.31`, `protego>=0.3.1`, `openpyxl>=3.1`만 적혀 있었다. 원래 설치 환경의 정확한 버전은 확정할 수 없다. `requirements.txt`는 이번에 실제 실행·검증한 환경을 고정한 것이다. 기본 CI도 Python 3.12를 사용한다. CI 설정을 작성한 것과 GitHub에서 실제 실행 완료한 것은 구별한다.
